# استكمال فحص عرض المخرجات

## المطلوب
استكمال مراجعة الموجود فقط، وتصحيح عيوب الشكل والأحجام دون إضافة ميزات أو تغيير منطق الموظفين والتكاملات.

## نطاق العمل
1. فحص الرسائل أثناء الكتابة والانتظار والأخطاء، وبطاقات الإعلانات والموافقة والإحالة والنشر.
2. معاينة الصور والفيديو والصوت والمرفقات باستخدام عينات محلية واضحة، دون إرسال أو نشر خارجي.
3. معالجة التجاوز والقص وتزاحم النصوص والأزرار حيث يثبت الخلل؛ الحفاظ على تصميم الموقع الحالي.
4. اختبار عروض من 320 إلى 1920 بكسل، وتكبير النص 200%، والتنقل بلوحة المفاتيح، والتباين في الحالات المختبرة.
5. تحديث تقرير التغطية بنتائج كل نوع وحالة، مع الفصل بين العينات المحلية واختبارات الحساب الحية.

## التفاصيل التقنية
- استخدام المكونات الفعلية مع بيانات اختبار محلية وتجنب استدعاءات الكتابة الخارجية.
- فحص قواعد CSS المؤثرة قبل تعديلها؛ عدم حذف القواعد المكررة لمجرد التكرار.
- اختبار الالتفاف للنصوص العربية والمختلطة والروابط الطويلة والأرقام الكبيرة.
- تشغيل الاختبارات المتاحة والتحقق من أخطاء المتصفح بعد التعديلات.

## معيار الإنجاز وحدود التحقق
لكل حالة مختبرة: لا تجاوز أفقي للصفحة، لا تداخل للنصوص، وأزرار قابلة للوصول والقراءة؛ الجداول الكبيرة تمرر داخلياً.
اختبارات الحساب الحية غير متاحة حالياً لاتصال Supabase الخارجي؛ لن تُوصف العينات بأنها نتائج حية أو دليل على التفوق العالمي.
