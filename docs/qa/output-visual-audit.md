# مراجعة عرض مخرجات سهل — 19 سبتمبر 2026

## نطاق الجولة
فحص المكونات الموجودة فقط، دون تغيير ذكاء الموظفين أو إرسال بريد أو نشر محتوى. العينات المحلية تستخدم مكونات التطبيق الحقيقية؛ ليست نتائج مولّدة من حساب المستخدم.

## المراجع والمعايير
- إعادة تدفق المحتوى عند 320px: https://www.w3.org/WAI/WCAG22/Understanding/reflow
- الحد الأدنى لأهداف النقر 24×24 CSS px والاستثناءات: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum
- تباين النص: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- تكبير النص: https://www.w3.org/WAI/WCAG21/Understanding/resize-text
- اتجاه العربية والنص المختلط: https://www.w3.org/International/questions/qa-html-dir.en
- العزل الاتجاهي: https://www.w3.org/International/articles/inline-bidi-markup/index.en

هذه معايير قابلة للقياس، وليست شهادة امتثال أو مقارنة تثبت التفوق العالمي.

## حصر العرض
العرض المشترك: رسائل المستخدم، Markdown للموظفين الستة، عناوين وقوائم واقتباسات وجداول وأكواد وروابط وصور، وقت الرسالة وأزرارها، الانتظار والتدفق، الأخطاء وطلبات الربط.
البطاقات: PostCards/PublishPanel، PostMediaGallery، PostQuality، InlineApproval، ActionCard، HandoffCard، PublishToWordPress.
الأدوات المرتبطة: MediaStudio، ReelStudio، AdsResultsCard، BrandVoiceExtractor، صفحات المهام والتقارير.

## نتائج مثبتة
- معاينة عينات نصية للموظفين الستة وصورة عرضية وأخرى طولية ومعرض صور وبطاقة جودة منشور وبطاقة مراجعة إجراء.
- العروض: 320، 375، 390، 451، 640، 768، 1024، 1280، 1440، 1920 CSS px؛ ارتفاع الاختبار 1800px.
- عرض المستند يساوي عرض الشاشة في الحالات العشر؛ لا تمرير أفقي على مستوى الصفحة.
- الجدول يحتفظ بـ display: table ويتم تمريره داخل الحاوية.
- أزرار العينات جميعها مسماة، ولا يقل أي منها عن 24×24px.
- فتح تفاصيل الجودة وحقول مراجعة الإجراء يعمل؛ لم يُضغط زر التنفيذ.
- التالي في المعرض يغير الصورة؛ التكبير يعمل، Tab يبقى داخل المعاينة، Escape يغلقها ويعيد التركيز إلى زر الفتح.
- لا أخطاء JavaScript في التشغيل النهائي للعينات.
- 136 اختباراً محلياً ناجحاً و994 تحققاً؛ هذه اختبارات منطق وليست اتصالاً حياً.
- فحص ESLint للملفات المعدلة ناجح.

## التصحيحات
- منع تمدد الرسائل والتفاف شريط الإجراءات.
- إصلاح تخطيط عنوان بطاقة الجودة وإعلان حالة فتحها.
- تكبير زر حذف المصغرات إلى الحد الأدنى وإزالة قصه عند حافة الشريط.
- استخدام نافذة حوار تدير التركيز في معاينة الوسائط، مع إرجاعه بعد الإغلاق.
- تصحيح ارتفاع المعاينة داخل الشاشة.
- منع قاعدة الهاتف من تحويل الجداول إلى كتل غير جدولية.
- تحديد اتجاه كل فقرة وعنوان بشكل مستقل وعزل الأكواد.
- تحسين عرض حقول مراجعة الإجراء وتوزيع أزرارها دون تغيير التنفيذ.

## حدود التغطية
لم تُختبر دورة نشر حية أو كل بيانات الحساب؛ لم تكتمل معاينة الفيديو والصوت والمرفقات وWordPress والموافقة والإحالة وتقارير الإعلانات وجميع حالات الانتظار/الخطأ ضمن المحادثة الكاملة. لم يكتمل قياس التباين لكل الحالات، تكبير النص 200%، أو اختبار Safari/Firefox والأجهزة الفعلية. وجود قواعد CSS متكررة يستدعي اختباراً موجهاً؛ التكرار وحده ليس دليلاً على خلل ولا مبرراً لإعادة كتابة التصميم. لا يوجد إثبات لكون المنتج الأفضل عالمياً.
